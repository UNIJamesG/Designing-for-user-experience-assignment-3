# Designing-for-user-experience-assignment-3
This website was created to be an online free encyclopedia that features a trending page that showcases the current trends happening, there have been some changes to the original design due to it being very difficult to program and overly complex, ive instead opted for a more simplistic gray scale style which primarily uses black and white colour schemes and more clearly showcases whats being talked about without having to rely on fancy animations and such.
Instructions: To begin you will be greeted with the home page, this home page has a search bar at the top left which can be used to search up anything on the internet you wish to research about (due to the inability to have such a feature it is just there for visual representation), you will also see the name of the website and underneath that you can find the "view trending" button which when clicked on will take you to a seperate page.
That page is the Trending Page, this page showcases the current trends happening right now, which in this case is currently 4 of them, Micheal Jordan, China, Nike and Napoleon, due to the nature of this website only requiring 3 pages to be showcased the only functional page that can be clicked on right now is the one regarding Micheal Jordan, there is also a back to home page button if you wish to return to the home page where the search function is.
When clicking on Micheal Jordan you will be brought to his main page which goes more in depth into him, whilst also showcasing a banner of him at the top, this page shows off the title of whats being looked at, which in this case is Micheal Jordan, it also then shows paragraphs all relating to him, when your finished taking a look at the main page you can click on the button at the bottom of the screen which takes you back to the main page where the search function and trending button are at.
